# Frente: Reconhecimento Óptico de Caracteres (OCR)

Esta frente tem como objetivo a transcrição automatizada de manuscritos, cartas e documentos digitados do acervo de Portinari através de modelos de OCR e Visão Computacional.

---

## Status
* **Planejada para etapas futuras.**
* Acervo de imagens e documentos manuscritos será processado a partir das coleções de documentos do acervo.
