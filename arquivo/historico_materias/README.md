# Histórico de Matérias (Notícias G1)

O dataset `Historico_de_materias.csv` (~32MB) contém o histórico arquivado de matérias jornalísticas e foi realocado para o **Google Drive** do Projeto Portinari.

---

## Como Obter os Dados
* Solicite acesso à pasta do Google Drive do projeto via e-mail institucional.
* Baixe o arquivo e posicione-o em `data/Historico_de_materias.csv` ou nesta pasta localmente.
* Este arquivo está listado no `.gitignore` e não deve ser comitado no GitHub.
